ACS H5P Viewer 0.1.0 - personal transfer pack for Directory Opus

Agent-assisted setup: copy the prompt in AGENT-SETUP-PROMPT.md from a newly
generated pack, or open https://github.com/dgcruzing/acs-h5p-opus-viewer/blob/main/docs/AGENT-SETUP-PROMPT.md
The prompt detects source versus prebuilt folders and uses the checks below.

1. Copy the ZIP to your other Windows PC. Right-click it > Extract All.
   Use a writable local folder and keep this extracted folder for verification/uninstall.
   Do not run the scripts from inside the ZIP.
2. The target needs Directory Opus 13 x64, Node.js x64 LTS (22 or later),
   and the Microsoft Edge WebView2 Evergreen Runtime. No compiler is required.
   DopusWorX is optional and is not altered.
3. Run Check.cmd. It verifies the package hashes and all three prerequisites.
   If something is missing, install it from the official links below and retry.
4. Exit Directory Opus normally, then run Install.cmd. Accept Windows elevation.
   Setup detects the local Opus/Node paths and writes the target runtime config.
5. Reopen Opus > Settings > Preferences > Viewer > Plugins > Refresh.
   Confirm ACS H5P Viewer is enabled and click OK.
6. Copy your .h5p lessons separately. Select one with the Opus viewer pane open.
   Use Reload after changing a package. Widen the pane as needed.
7. Run Verify.cmd and complete VERIFY.txt on the other PC.

Prerequisite downloads (not bundled or automatically installed):
Directory Opus: https://www.gpsoft.com.au/
Node.js x64 LTS: https://nodejs.org/en/download/
WebView2 Evergreen Runtime: https://developer.microsoft.com/en-us/microsoft-edge/webview2/
For a PC without internet, obtain the Node Windows x64 MSI and WebView2 Evergreen
Standalone Installer x64 beforehand. The WebView2 bootstrapper requires internet.
Playback uses the bundled player and loopback resources once prerequisites exist.

CUSTOM PATHS (PowerShell opened in this extracted folder):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -Action Check -OpusDirectory 'E:\Apps\Directory Opus' -NodePath 'E:\Apps\Node\node.exe'
Use -Action Install with those same options to install.
These E: paths are examples; substitute paths on the target PC.

UPDATES AND CONFLICTS:
Default installation stops if ACS viewer files already exist. Other plugins are untouched.
After reviewing the existing installation, use -Action Install -Force to back up the
old ACS DLL/assets under this extracted folder's backups directory and replace them.
The existing local Node setting is preferred when valid. An explicit -NodePath overrides it.
Keep the backup until the updated installation passes checks. No Opus process is killed.
For rollback, exit Opus, restore the saved ACS DLL/assets together; do not mix releases.

UNINSTALL:
Exit Opus normally and run Uninstall.cmd. It checks this pack's installed file hashes
and refuses changed or unrecognised files. It removes only the ACS DLL and its assets.
Logs/profiles under %LOCALAPPDATA%\ACS\H5PViewer are retained.
Uninstall.cmd applies to installations made by this transfer package, not older installers.

NOTES:
This is an unsigned personal prototype, not a publicly released installer.
Its expected UAC prompt runs Windows PowerShell. Follow your organisation's software policy.
Setup-result.txt contains the last install/uninstall result or failure message.
Hash checks detect accidental corruption; the manifest is not a digital signature.
If using a different administrator account for UAC, install Node and WebView2 for all
users so both that account and the Opus user can access them.
This pack does not include lessons, credentials, browser profiles, or diagnostic ports.
Windows x64 is the intended target; ARM64 and x86 are not accepted by this prototype.
The source machine passed DLL-host media tests and actual Opus rendering/switching.
Full media/focus/lifecycle acceptance inside Opus and on this second PC still needs checking.
Retain all licences and notices. Source is included for the ACS components; upstream
source references remain in the bundled notices. Public redistribution clearance is pending.
